# Списки

## 1. Проверить, является ли список циклическим (`01-HasCycle.cpp`)

Дан односвязный список. Необходимо определить, является ли он циклическим.

**Примеры:**

```text
Циклический список:
1 -> 2 -> 3 -> 4 -> 5
          ↑         │
          └─────────┘

Линейный список:
1 -> 2 -> 3 -> 4 -> 5 -> nullptr
```

## 2. Развернуть односвязный список (`02-ReverseLinkedList.cpp`)

Написать функцию, которая принимает односвязный список и разворачивает его.

**Пример:**

```text
Список:     1 -> 2 -> 3 -> 4 -> nullptr
Результат:  4 -> 3 -> 2 -> 1 -> nullptr
```

## 3. Найти середину списка (`03-MiddleNode.cpp`)

Дан связный список. Необходимо найти его середину за `O(n)` времени и без дополнительных аллокаций. Для списка чётной длины программа возвращает второй из двух центральных узлов.

**Пример 1:**

```text
Список: 1 -> 2 -> 3 -> 4 -> 5 -> nullptr
Ответ:  узел со значением 3
```

**Пример 2:**

```text
Список: 1 -> 2 -> 3 -> 4 -> 5 -> 6 -> nullptr
Ответ:  узел со значением 4
```

## 4. Удалить элементы по значению (`04-RemoveElementByVal.cpp`)

Дан односвязный список и целое число `val`. Необходимо удалить из списка все узлы, значения которых равны `val`.

**Пример:**

```text
Список: 1 -> 2 -> 2 -> 3 -> 2 -> nullptr
val:    2
Ответ:  1 -> 3 -> nullptr
```

## 5. Удалить n-й узел с конца списка (`05-RemoveNthFormEnd.cpp`)

Даны голова односвязного списка и целое число `n`. Необходимо удалить `n`-й узел с конца и вернуть обновлённый список.

**Пример:**

```text
Список: 1 -> 2 -> 3 -> 4 -> 5 -> nullptr
n:      2
Ответ:  1 -> 2 -> 3 -> 5 -> nullptr
```

## 6. Проверить, является ли одна строка исходной для другой (`06-IsSubsequence-v1.cpp` и `06-IsSubsequence-v2.cpp`)

В строку `b` добавили некоторое количество символов. Необходимо определить, могла ли строка `a` быть исходной.

Задача реализована в двух вариантах: с очередью (`v1`) и двумя указателями (`v2`). Вариант с очередью требует `O(n)` дополнительной памяти, а вариант с двумя указателями — `O(1)`.

**Пример 1:**
```text
a:     "abd"
b:     "uabqd"
Ответ: true
```
**Пример 2:**
```text
a:     "abd"
b:     "uaqd"
Ответ: false
```
**Пример 3:**
```text
a:     "a"
b:     "aa"
Ответ: true
```

## 7. Проверить, является ли строка палиндромом (`07-IsPalindrome-v1.cpp`, `07-IsPalindrome-v2.cpp` и `07-IsPalindrome-v3.cpp`)

Написать функцию, которая принимает строку и возвращает `true`, если она является палиндромом. В противном случае вернуть `false`.

Задача реализована в трёх вариантах: с использованием стека (`v1`), дека (`v2`) и двух указателей (`v3`). Стек и дек требуют `O(n)` дополнительной памяти, двум указателям достаточно `O(1)`.

**Пример 1:**
```text
str:   "abba"
Ответ: true
```
**Пример 2:**
```text
str:   "abcde"
Ответ: false
```

## 8. Отсортировать массив с помощью дополнительного стека (`08-SortArrayUsingStack.cpp`)

Дан массив целых чисел. Необходимо отсортировать его, используя дополнительный стек.

**Пример:**

```text
Массив: [5, 1, 4, 2, 8, 3]
Стек:   [1, 2, 3, 4, 5, 8] (от дна к вершине)
```

## 9. Объединить два отсортированных списка (`09-MergeSortedLists.cpp`)

Даны два отсортированных односвязных списка. Необходимо объединить их в один отсортированный список, используя `O(1)` дополнительной памяти.

**Пример:**
```text
[3, 6, 8] и [4, 7, 9, 11] --> [3, 4, 6, 7, 8, 9, 11]
```
