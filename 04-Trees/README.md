# Деревья

## 1. Восстановление бинарного дерево из массива (`01-BuildTreeFromArray.cpp`)

Дан массив, представляющий бинарное дерево. Необходимо восстановить структуру бинарного дерева.

В решении используется индексное представление из семинара: корень находится в элементе `0`, левый потомок элемента $i$ --- в $(2\cdot i + 1)$, правый --- в $(2\cdot i + 2)$. Для каждого существующего элемента рекурсивно создаётся узел `TreeNode` с указателями на левого и правого потомков. Индекс за границами массива соответствует отсутствующему узлу.

**Пример:**

```text
Массив: [8, 9, 11, 7, 16, 3, 1]

Дерево:

8
├── 9
│   ├── 7
│   └── 16
└── 11
    ├── 3
    └── 1
```

## 2. Симметричное бинарное дерево (`02-IsSymmetricTree.cpp`)

Дано бинарное дерево. Необходимо определить, является ли оно симметричным относительно своей середины.

Функция рекурсивно сравнивает симметричеые пары узлов. Для пары узлов проверяются их значения, затем левый потомок первого сравнивается с правым потомком второго, а правый сравнивается с левым. Пара симметрична, если оба узла отсутствуют либо их значения совпадают и обе пары потомков симметричны.

**Пример 1:**

```text
    1
   / \
  2   2
 / \ / \
3  4 4  3

Дерево симметрично
```

**Пример 2:**

```text
  1
 / \
2   3

Дерево несимметрично
```

## 3. Минимальная глубину бинарного дерева (`03-MinDepth.cpp`)

Дано бинарное дерево. Необходимо найти его минимальную глубину (расстояние от корня до ближайшего листа).

**Пример:**

```text
     8
   /   \
  9     11
 / \    / \
7  16  3   1

min depth: 3
```

## 4. Произведение минимального и максимального элементов BST (`04-MinMaxProduct.cpp`)

Дано бинарное дерево поиска (BST), представленное в виде массива.​ Необходимо найти произведение минимального и максимального значений.

Как на семинаре, используется индексное представление: левый потомок узла с индексом $i$ расположен по индексу $(2 \cdot i + 1)$, правый --- $(2 \cdot i + 2)$. В BST минимум находится в крайнем левом узле, максимум --- в крайнем правом. Для поиска пройдём по индексам левых и правых потомков.

**Пример:**

```text
Массив: [8, 4, 12, 2, 6, 10, 14]

     8
   /    \
  4      12
 / \    /  \
2   6  10  14

product: 28
```

## 5. Сравнение бинарных деревьев (`05-IsSameTree.cpp`)

Даны два бинарных дерева. Необходимо определить, являются ли они идентичными (по структуре и значениям узлов).

Рекурсивно сравниваются корни деревьев, затем соответствующие левые и правые поддеревья. Если оба узла отсутствуют, эта пара совпадает. Если отсутствует только один узел или значения различаются, деревья не идентичны.

**Примеры:**

```text
[1, 2, 3, 4] и [1, 2, 3, 4] --> true
[1, 2, 3, 4] и [1, 2, 3]    --> false
[1, 2, 3, 4] и [1, 2, 3, 5] --> false
```
