# Массивы

## 1. Два числа с заданной суммой (`01-TwoSum.cpp`)

Дан отсортированный по возрастанию массив целых чисел и некоторое число `target`. Необходимо найти два числа в массиве, которые дают в сумме значение `target`, и вернуть их индексы.

**Пример:**

```text
Массив: [2, 3, 4]
target: 6
Ответ:  (0, 2)
```

## 2. Развернуть массив (`02-ReverseArray.cpp`)

Дан массив целых чисел. Необходимо развернуть его за линейное время без дополнительных аллокаций.

**Пример:**

```text
[1, 2, 3, 4] --> [4, 3, 2, 1]
```

## 3. Циклический сдвиг массива  (`03-ShiftArray.cpp`)

Дан массив целых чисел и неотрицательное число `k`. Необходимо выполнить циклический сдвиг массива влево на `k` позиций.

**Пример:**

```text
Массив: [1, 2, 3, 4, 5, 6, 7]
k:      3
Ответ:  [5, 6, 7, 1, 2, 3, 4]
```

## 4. Слияние отсортированных массивов (`04-MergeSortedArrays-v1.cpp` и `04-MergeSortedArrays-v2.cpp`)

Задача реализована в двух вариантах — с аллокацией (`v1`) памяти и без (`v2`). 

Даны два отсортированных массива. Необходимо объединить их в один отсортированный массив.

**Пример:**

```text
[1, 4, 5, 7] и [1, 2, 3, 6, 9] --> [1, 1, 2, 3, 4, 5, 6, 7, 9]
```

## 5. Минимальная длина подмассива (`05-MinSubArray.cpp`)

Дан массив положительных целых чисел и число `target`. Необходимо найти минимальную длину непрерывного подмассива, сумма элементов которого не меньше `target`.

Если такого подмассива не существует, верните `0`.

**Пример:**

```text
Массив: [1, 2, 3, 4, 5]
target: 6
Ответ:  2
```

## 6. Отсортировать бинарный массив (`06-SortBinaryArray.cpp`)

Дан массив, содержащий только `0` и `1`. Необходимо переставить элементы так, чтобы сначала шли все нули, а затем все единицы.

**Пример:**

```text
[0, 1, 1, 0, 1, 0] --> [0, 0, 0, 1, 1, 1]
```

## 7. Сортировка трёх цветов (`07-SortColors.cpp`)

Дан массив, содержащий числа `0`, `1` и `2`. Необходимо отсортировать его так, чтобы сначала шли нули, затем единицы, затем двойки.

**Пример:**

```text
[0, 1, 2, 1, 0, 2] --> [0, 0, 1, 1, 2, 2]
```

## 8. Чётные числа в начало (`08-EvenFirst.cpp`)

Дан массив целых чисел. Необходимо переставить элементы так, чтобы все чётные числа оказались перед нечётными, сохранив при этом взаимный порядок чётных чисел и взаимный порядок нечётных чисел.

**Пример:**

```text
[1, 2, 3, 4, 5, 6] --> [2, 4, 6, 1, 3, 5]
```

## 9. Переместить нули в конец (`09-ZeroesToEnd.cpp`)

Дан массив целых чисел. Необходимо переставить все нули в конец массива, сохранив взаимный порядок ненулевых элементов.

**Пример:**

```text
[0, 1, 0, 3, 12] → [1, 3, 12, 0, 0]
```
