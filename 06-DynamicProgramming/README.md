# Динамическое программирование

## 1. Наибольшая непрерывная возрастающая последовательность (`01-FindLIS.cpp`)

Дан неотсортированный массив чисел. Необходимо найти максимально длинную непрерывную возрастающую последовательность и вернуть её длину.

Проходим по массиву слева направо и сравниваем соседние элементы. Если следующий элемент больше предыдущего, увеличиваем `current` (длину текущего участка). Иначе начинаем новый участок длины `1`. Переменная `max` хранит наибольшую длину, которую встретили за весь проход.

Время работы $O(n)$. Дополнительной памяти нет.

**Примеры:**

```text
[3, 2, 8, 9, 5, 10] --> 3, последовательность [2, 8, 9]
[1, 2, 7, 9, 0, 10] --> 4, последовательность [1, 2, 7, 9]
[8, 8, 8, 8]        --> 1, последовательность [8]
```

## 2. Треугольник Паскаля (`02-PascalTriangle.cpp`)

Дано число `n`. Необходимо построить треугольник Паскаля из `n` строк.

Строки строятся в цикле сверху вниз. Строка с индексом `i` содержит `i + 1` элементов. Сначала вся строка заполняется единицами, затем для каждой внутренней позиции `j` складываются элементы предыдущей строки с индексами `j - 1` и `j`.


**Пример.** При `n = 5` программа выводит:

```text
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

## 3. Размен монет (`03-CoinChange.cpp`)

Дан массив номиналов монет `coins` и число `amount`. Требуется найти минимальное количество монет, составляющих сумму `amount`, либо вернуть `-1`, если это невозможно.

`dp[i]` хранит минимальное количество монет для суммы `i`. Сначала `dp[0] = 0`, а остальные значения помечаем как недостижимые. Заполняем таблицу по возрастанию сумм. Если `coin <= i` и остаток `i - coin` достижим, добавляем к его размену одну монету и обновляем минимум `dp[i]`. Ответ храним в `dp[amount]`.

**Примеры:**

```text
coins = [1, 2, 5], amount = 7 --> 2
coins = [2]      , amount = 3 --> -1
coins = [1, 2, 5], amount = 0 --> 0
```

## 4. Самая длинная подстрока-палиндром (`04-LongestPalindrome.cpp`)

Дана строка `s`. Необходимо найти её самую длинную подстроку-палиндром.


Перебираем центры палиндромов. У палиндрома нечётной длины центр находится на символе, например на `b` в `aba`. У палиндрома чётной длины центр находится между символами, например между двумя `b` в `abba`.

От каждого центра расширяем границы, пока символы по краям совпадают. Так находим самый длинный палиндром для каждого центра. У любого палиндрома есть один из этих центров, поэтому достаточно запомнить начало и длину лучшего результата. При равной длине возвращается первое вхождение.

В худшем случае время работы $O(n^2)$. Дополнительной памяти нет.

**Примеры:**

```text
babad    --> bab
cbbd     --> bb
abcd     --> a
abbacfgh --> abba  
```
