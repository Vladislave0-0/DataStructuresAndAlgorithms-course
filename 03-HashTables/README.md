# Хеш-таблицы


## 1. Найти целую часть квадратного корня (`01-IntegerSqrt.cpp`)

Найти целую часть его квадратного корня, округлённую вниз.

Бинарный поиск ведётся на отрезке от `0` до `n`, потому что корень не может быть больше самого числа. Если квадрат середины не превышает `n`, середина подходит и можно искать ответ правее. Иначе поиск продолжается слева. Отрезок на каждом шаге сокращается вдвое, поэтому время работы — `O(log(n))`.

## 2. Очень лёгкая задача (`02-TwoCopiers.cpp`)

Есть оригинал документа и два ксерокса, которые делают одну копию за `x` и `y` единиц времени. Необходимо найти минимальное время для изготовления `N` новых копий. Ксероксы могут работать одновременно, а сделанную копию можно использовать как оригинал.

Первую копию делает более быстрый ксерокс за `min(x, y)`. После этого бинарным поиском находится минимальное дополнительное время `t`, за которое оба ксерокса успеют сделать ещё `N - 1` копий. Условие достаточности:

$$
\frac{t}{x} + \frac{t}{y} \geqslant N-1,
$$
где деление целочисленное. Верхняя граница поиска:

$$
(N-1)\cdot\min(x,\ y).
$$

## 3. Накормить животных (`03-FeedAnimals.cpp`)

Даны потребности животных в еде и размеры привезённых порций. Одна порция может накормить только одно животное и не делится. Необходимо найти наибольшее возможное число накормленных животных.

Отсортируем оба массива. Каждую порцию отдаём самому нетребовательному ещё не накормленному животному, которому её хватает. Если порция слишком мала даже для него, она не подойдёт и остальным. Время работы:

$$
O\big(a\cdot\log(a) + f\cdot\log(f)\big),
$$
где `a` и `f` — числа животных и порций.

## 4. Найти добавленную букву (`04-FindExtraLetter.cpp`)

Строка `b` получена перемешиванием символов строки `a` и добавлением одной буквы. Необходимо найти добавленную букву без сортировки.

Хеш-таблица хранит число вхождений каждого символа в `b`. Для символов из `a` счётчики уменьшаются; положительный остаток соответствует добавленному символу.

Время работы в среднем:
$$
O(\lVert a\rVert + \lVert b\rVert).
$$

## 5. Сумма двух элементов массива (`05-TwoSum.cpp`)

Дан неотсортированный массив целых чисел и число `target`. Необходимо найти индексы двух разных элементов, сумма которых равна `target`.

При проходе по массиву хеш-таблица хранит значения уже просмотренных элементов и их индексы. Для текущего числа ищем `target - number` среди предыдущих. В среднем алгоритм работает за `O(n)` времени и использует `O(n)` дополнительной памяти.

## 6. Сгруппировать анаграммы (`06-GroupAnagrams.cpp`)

Дан массив строк `strs`. Необходимо сгруппировать анаграммы. Группы можно вернуть в любом порядке. Анаграммы содержат одинаковые символы с одинаковым числом повторений, но их порядок может различаться.

Ключом хеш-таблицы явлется массив частот всех возможных значений байта. Строки с одинаковым ключом попадают в одну группу. Для строки длины `k` подсчёт символов занимает `O(k)`. При фиксированном алфавите общее время линейно по суммарной длине строк.
