# Деревья

## 1. Полное бинарное дерево (`01-IsCompleteTree.cpp`)

Реализовать функцию, которая проверяет, является ли заданное бинарное дерево полным.

Для решения используется обход в ширину. После первой отсутствующей дочерней ссылки все следующие ссылки в порядке обхода тоже должны быть пустыми. Если после пропуска встречается узел, дерево неполное. В примере массив задаёт дерево по индексам; `nullopt` обозначает отсутствующий узел.

**Примеры:**

```text
Массив: [1, 2, 3, 4, 5, 6]

    1
   / \
  2   3
 / \ /
4  5 6

Дерево полное
```

```text
Массив: [1, 2, 3, 4, null, 6]

    1
   / \
  2   3
 /   /
4   6

Дерево неполное
```

## 2. Объединить K отсортированных массивов (`02-MergeKSortedArrays.cpp`)

Реализовать функцию, объединяющую `K` отсортированных массивов в один отсортированный массив.

Мин-куча хранит текущий минимальный элемент каждого непустого массива вместе с его индексами. После извлечения минимума в результат добавляется следующий элемент из того же массива. Для `N` элементов общее ожидаемое время — $O\left(N\cdot\log(K)\right)$, дополнительная память для кучи — $O(K)$.

**Пример:**

```text
{[1, 4, 7], [2, 5], [], [3, 6, 9]} --> [1, 2, 3, 4, 5, 6, 7, 9]
```

## 3. K-й наименьший и K-й наибольший элементы массива (`03-KthElementInArray.cpp`)

Дан массив чисел. Необходимо найти `K`-ый наименьший или `K`-ый наибольший элемент.

Для решения используются min-куча и max-куча. Для `k`-го наименьшего элемента поддерживается max-куча из `k` наименьших просмотренных значений. Её вершина — наибольший из них, то есть текущий кандидат на `k`-й элемент. Для `k`-го наибольшего используется min-куча из `k` наибольших значений. Время — $O\left(n\cdot\log(k)\right)$, дополнительная память — $O(k)$.

**Пример:**

```text
Массив: [7, 4, 6, 3, 9, 1]
k = 2

2-й наименьший: 3
2-й наибольший: 7
```

## 4. K-й наименьший и K-й наибольший элементы в BST (`04-KthElementInBST.cpp`)

Дано бинарное дерево поиска.​ Реализовать алгоритм нахождения `K`-ого наименьшего или наибольшего элемента, используя свойства BST и обход дерева.

**Пример:**

```text
BST: [8, 4, 12, 2, 6, 10, 14]

3-й наименьший: 6
2-й наибольший: 12
```

## 5. balance factor каждого узла (`05-BalanceFactor.cpp`)

Для каждого узла BST необходимо заполнить поле `balance_factor` — разницу высот его левого и правого поддеревьев. В этой реализации используется соглашение `высота(левого) - высота(правого)`; высота пустого поддерева равна `0`.

На вход функции передаётся указатель на корень бинарного дерева поиска.​ Необходимо для каждого узла вычислить и заполнить поле `balance_factor` (разницу высот левого и правого поддеревьев).

Обход выполняется снизу вверх. Рекурсивно сначала получаем высоты обоих поддеревьев, записываем их разницу в текущий узел и возвращаем высоту текущего поддерева. Каждый узел обрабатывается один раз: время — `O(n)`.

**Пример:**

```text
BST: [8, 4, 12, 2]

Узел: balance_factor
2:    0
4:    1
8:    1
12:   0
```

## 6. Преобразовать дерево в зеркальное (`06-MirrorTree.cpp`)

Реализовать алгоритм зеркального отражения бинарного дерева, меняя местами левые и правые поддеревья каждого узла.​

Для каждого узла меняются местами указатели `left` и `right`, после чего та же операция рекурсивно применяется к детям. Каждый вызов корректно отражает оба поддерева, после обработки корня зеркально отражено всё дерево, то есть такой рекурсивный набор операций эквивалентен группе $O(2)$.

**Пример:**

```text
До:    1 2 3 4 5 6 7
После: 1 3 2 7 6 5 4
```
